# Teachers' Day Message Card 📖🍎

An interactive Teachers' Day digital message card made with **HTML, CSS, and JavaScript**.

## Features

- 📖 3D book-style opening/closing animation
- ✨ Floating sparkle effects
- 🎉 Celebration/confetti animation
- ✍️ Custom teacher name
- 💌 Custom personal message
- 👤 Custom sender name
- 📸 Upload and preview a teacher photo
- 🎵 Upload and play a personal audio greeting
- 📱 Responsive design for desktop and mobile
- ♿ Keyboard-accessible card opening
- 🔄 Reset button
- 🚫 No database required

## Project Files

```text
teachers_day_message_card/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Keep all four files in the same folder.
3. Open `index.html` in a modern web browser.
4. Click **Customize Card**.
5. Enter the teacher's name, your name, and your message.
6. Upload a photo and/or audio greeting.
7. Click **Apply Changes**.
8. Click the card cover to open it like a book.

## Notes

- Uploaded photo and audio files are previewed locally in the browser using temporary object URLs.
- Nothing is uploaded to a server and no database is required.
- For GitHub Pages, upload the four project files to a public repository and enable GitHub Pages.
